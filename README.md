Cisco Secure Firewall is the product line built on the Sourcefire technology Cisco acquired in 2013 — the Firepower/Secure Firewall appliances and Threat Defense (FTD) software, the Secure Firewall Management Center (FMC), the on-box device manager (FDM), and the cloud-delivered Firewall Management Center (cdFMC) operated under Cisco Security Cloud Control. Programmatic management runs through two published REST contracts: the cdFMC API (1,311 operations across 706 paths, covering devices, policy, objects, deployment, health, licensing and analysis) and the Security Cloud Control Firewall Manager API (160 operations covering inventory, connectors, transactions, changelogs, search and remote-access VPN monitoring). Both are bearer-JWT authenticated, region-scoped across US/EU/APJ/AU/IN, and published first-party by Cisco in the CiscoDevNet scc-public-api-docs repository that backs developer.cisco.com. Automation is further supported by a Python SDK, an Ansible collection, a Terraform provider, Postman collections and community MCP servers.

**Areas:** Security · Firewall · Network Security · Threat Defense · Policy · Enterprise · Firewall Management · Cloud Security · Networking · Automation
